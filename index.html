기본값

데이터 관리

데이터는 클라우드(Firebase)에 저장되어 이 주소로 접속한 모든 기기가 함께 씁니다. 이 기기에도 사본이 남아 인터넷이 잠깐 끊겨도 쓸 수 있고, 연결되면 자동으로 올라갑니다. 처음 배포할 때는 예전 버전에서 만든 백업 파일을 여기서 불러오세요.

신고자 명단

현상 → Level 2 분류표

사용방법 v5.2

1. 기본 흐름

① 접수 — 접수관리 → 「TOS 데이터 붙여넣기」에서 TOS 엑셀의 데이터 행(A~AE열)을 복사해 붙여넣습니다. 이미 있는 TOS번호는 자동으로 건너뜁니다.
② 현황 확인 — 메인화면 위쪽 카드(진행중·7일 초과·점검내용 미입력·완료·전체)로 목록을 거릅니다. 행 왼쪽 색 띠는 처리 시급도입니다.
③ 점검 요청 — 메인화면 체크박스로 대상을 고르고(최대 30건) 점검요청서에서 노란 칸을 채운 뒤 「인쇄 / PDF 저장」을 누릅니다.
④ 완료 처리 — 접수관리에서 건을 고르고 오른쪽 입력창의 ① 완료 처리 · ② 작업 내용 · ③ 자재·비용을 입력합니다. ↑ ↓ 키로 다음 건으로 넘어갑니다.
⑤ 작업완료보고서 — 작업완료보고서 메뉴에서 정산월(또는 기간)을 고르면 완료건이 자동으로 채워집니다. Comp. 압력과 사진을 넣고 인쇄 / PDF 또는 엑셀로 내보냅니다.
⑥ A/S리스트 — 접수관리 건 중 S/N이 등록된 장비는 A/S리스트에 자동으로 올라갑니다. 행을 눌러 crm접수번호·고장 유형·교체 부품 등을 채우고 엑셀로 내보냅니다.

2. 작업완료보고서

· 기간: 현재 정산월(기본) / 정산월 선택 / 기간 직접 선택. 정산월은 설정의 정산 시작일 기준입니다(21일이면 전월 21일 ~ 해당월 20일).
· 자동 입력: 구분·Level 1 = 기본 구분, Level 2 = 현상 분류표, Level 3·비용구분 = 접수관리 입력값(없으면 기본값), 소속·연락처 = 신고자 명단, S/N(자산번호) = 장비마스터, 원인 분석 = 점검내용, 작업 내용 = 수리완료내용.
· 직접 입력: Comp. 압력 5칸(노란 칸)과 작업 전·후 사진. 사진은 자동으로 줄여 저장되지만 브라우저 저장 공간을 쓰므로 정산이 끝나면 백업 후 정리하세요.
· 내보내기: 인쇄 / PDF(A3 가로 권장, A4 가로 가능), 엑셀(.xlsx — 기존 보고서와 같은 2단 머리글·합계), CSV. 엑셀 파일에는 사진 대신 「첨부」가 표시됩니다.
· 아래쪽 정산내역 표에서 최근 6개 정산월의 완료 건수·유상/무상·자재금액을 보고 「보고서 보기」로 바로 엽니다.

3. A/S리스트

· 누적 이력: A/S리스트 최종본(Rev07) 931행이 들어 있습니다. 「+ 행 추가」로 한 행씩, 「엑셀 붙여넣기」로 엑셀에서 복사한 여러 행을 한 번에 추가합니다.
· 엑셀 붙여넣기: 엑셀 취합 시트에서 행(머리글 포함 가능)을 복사해 붙여넣으면 신규 · 기존과 같음 · 오류로 먼저 보여 주고, 「반영」을 눌러야 저장됩니다. 기존과 같은 행(S/N·접수일·접수 내용·교체 부품 동일)은 건너뛰거나, 빈칸만 채우거나(예: 나중에 받은 crm접수번호), 덮어쓸 수 있습니다. 반영 직후 「되돌리기」가 가능합니다.
· 자동 등록: 설정의 「A/S리스트 자동 등록」 기준(접수 즉시 / 완료 후, 대상 접수일)으로 접수관리 건이 자동 표시됩니다. 같은 S/N·접수일 행이 이력에 있으면 중복으로 보고 건너뜁니다. 고정값(등록구분·접수방법·고객명 등)도 설정에서 바꿉니다.
· 자동 계산: crm작성일자(빈칸일 때만 접수번호로), 위치(시/도), 담당자 연락처·메일, 중분류·대분류, 접수/완료 주차, 리드타임(공휴일 제외 영업일), 처리기간, 정보누락, 계열은 엑셀 수식과 같은 규칙으로 계산됩니다.
· 내보내기: 현재 목록을 엑셀(.xlsx, A~AP열·필터 포함), CSV, 또는 「엑셀 붙여넣기용 복사」로 기존 엑셀이나 CRM 등록용 파일에 옮깁니다.

4. 주의 사항

· 데이터는 사용하는 브라우저에 저장됩니다. 사이트 데이터를 지우면 사라지므로 주기적으로 설정 → 「백업 파일 저장」을 해 주세요(사진·A/S리스트 포함).
· 여러 명이 동시에 같은 데이터를 공유하는 기능은 없습니다(서버 없음). 백업 파일로 주고받습니다.
· 공휴일 목록은 설정에서 해마다 추가해 주세요(현재 2026년 15일).
